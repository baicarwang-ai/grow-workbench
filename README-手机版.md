# 个人成长工作台 · 手机版

在手机上使用「个人成长工作台」，界面、功能、数据与电脑版**完全一致**（同一套代码），并针对手机屏幕做了 App 化适配：

- 📱 桌面左侧导航 → 手机**底部标签栏**（作息/饮食/健身/阅读）
- 🗂️ 卡片自动变为单列，日历、菜谱、教程全部触控优化
- 📲 支持 **PWA 安装**：添加到主屏幕后变成全屏 App，离线也能打开
- 💾 数据存在手机浏览器本地，可用「导出/导入数据」与电脑版互相同步

## 一、手机上打开（三种方式）

### 方式 A：公网访问（随时随地，推荐）

已经部署到 GitHub Pages，**手机浏览器直接打开（无需电脑开机、无需同 WiFi）：**

**https://baicarwang-ai.github.io/grow-workbench/**

打开后点页面顶部的「📱 安装到手机主屏幕」提示，即可变成全屏 App，离线也能使用。

> 仓库：https://github.com/baicarwang-ai/grow-workbench
> 更新方法：修改代码后 `git add -A && git commit -m "..." && git push`，Pages 约 1 分钟自动更新。

### 方式 B：局域网访问（立即可用）

1. 双击本目录下的 **`启动手机版.bat`**（需电脑已安装 Node.js）
2. 手机连上**与电脑同一个 WiFi**
3. 手机浏览器打开启动窗口里显示的地址，例如：`http://192.168.3.9:8341`
4. 也可以用手机浏览器扫电脑屏幕上的二维码（用二维码生成工具把该地址转成二维码）

> 首次打开后，建议点击页面顶部的「📱 安装到手机主屏幕」提示，把它变成全屏 App。
> 服务器关闭后电脑上的旧页面将无法访问，但已安装到主屏幕的 PWA 可离线使用。

### 方式 C：部署到其他平台（可选）

把整个文件夹上传到任意静态托管（Netlify / Vercel / 腾讯云 COS 等）即可获得其他公网链接。

## 二、与电脑版的数据同步

手机版和电脑版各自把数据保存在本地浏览器，互不自动同步。同步方法：

1. 在**电脑版**点底部「导出数据」，得到 `.json` 备份文件
2. 把文件传给手机（微信文件传输助手等）
3. 在**手机版**点「导入数据」，选择该文件即可

## 三、手机版新增 / 改动

| 文件 | 说明 |
| --- | --- |
| `css/mobile.css` | 手机端适配样式（≤768px 生效，平板 769–1024px 微调） |
| `manifest.json` | PWA 配置（应用名、图标、全屏模式） |
| `sw.js` | Service Worker，离线缓存 |
| `icons/` | 应用图标（SVG 源文件 + 192/512 PNG） |
| `scripts/serve.js` | 局域网静态服务器（监听 0.0.0.0） |
| `启动手机版.bat` | 一键启动服务器 + 打开页面 |
| `index.html` | 新增 PWA meta、安装引导横幅、SW 注册 |

**未改动**：`css/style.css`、`js/data.js`、`js/app.js`、`img/` 与电脑版完全一致——保证功能一模一样。

## 四、常见问题

- **手机打不开**：确认手机和电脑在同一 WiFi；关闭电脑防火墙或允许 Node 通过；确认地址端口正确。
- **修改图标**：改 `icons/icon-source.svg` 后运行 `node scripts/gen-icons.js` 重新生成。
- **换端口**：`PORT=9999 node scripts/serve.js`。
